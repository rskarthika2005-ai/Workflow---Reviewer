How the status is decided

CHANGES_REQUIRED

Any blocker finding. The artifacts route a ticket differently.

INCOMPLETE

Something could not be reviewed (unsupported text, approval conflict, oversized input, failed check).

PASS

No findings and nothing left unreviewed. Decided in code, not by the model.

Limitations

  • Small self-written set of 14 bundles, so it is not a general accuracy claim.
  • Only the fake model client was used. No real-model results.
  • Equivalence is checked on the declared grid, not for arbitrary code.
  • Other ticket fields, loops and function calls in code are unsupported.
